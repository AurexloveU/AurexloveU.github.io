# Aurex · 计划台(Planner)

薰衣草色的四象限计划 / 待办系统。前端为**纯静态页面**(零依赖、零 CDN、可直接由
GitHub Pages 托管),后端为**可选**的 Node + Express 服务(不装不跑也完全不影响使用)。

> 母站风格:低饱和薰衣草紫 · 中文衬线(Noto Serif SC / Songti / SimSun 系统字体栈)。

---

## 功能一览

| 模块 | 说明 |
|---|---|
| **今日聚焦** | 问候语 + 「现在专注」大卡片(自动挑最要紧的一件)+ 逾期清单一键顺延 + 今日清单 |
| **四象限(日)** | 艾森豪威尔矩阵,任务卡片可**拖拽换象限**、上下拖拽排序,每个象限一键快速添加 |
| **周视图** | 七列一周,卡片**跨天拖拽**改期,点列头进入那天的四象限 |
| **月视图** | 缩略格:每天的格子用**象限彩点 + 待办数字**(全部完成显示 ✓)标示状态;点某天**就地展开当天四象限**;卡片可直接拖进月历任意格子改期 |
| **任务属性** | 优先级(高/中/低)· 标签 · 截止日(逾期高亮)· 进度条(点一下 +25%)· 重复(每日 / 每周选星期 / 每 N 天) |
| **统计** | 近 30 天完成率(环形)· 连击天数(连续全勤日)· 累计完成 · 近 20 周**热力图** · 近 14 天完成条形图 · 象限分布 · 标签排行 |
| **键盘流** | `N` 快速添加(带语法解析)· `1–5` 切视图 · `←→` 翻页 · `Ctrl+Z` 撤销 / 重做 · `E` 导出 · `?` 帮助 |
| **导出 ICS** | 一键导出 `.ics`:重复任务生成标准 `RRULE`,含截止日的任务附带 `VTODO`,可导入任意日历应用 |
| **数据** | localStorage 离线独立工作;配置后端后按 `updatedAt` **双向合并同步**(删除用墓碑传播,断网无感降级) |

### 快速添加语法(可组合、顺序随意)

```
写周报 #工作 !1 p:高 @明天 due:周五 r:周一三五 %30
```

- `#标签`(可多个) · `!1..!4` 象限 · `p:高/中/低` 优先级
- `@今天 @明天 @后天 @周五 @08-15 @2026-08-15 @+3` 安排日
- `due:…` 截止日(语法同上) · `r:日` / `r:周一三五` / `r:3天` 重复 · `%40` 初始进度

## 运行方法

### 前端(无需任何构建)

- **本地**:直接双击打开 `planner/index.html` 即可(全部功能离线可用);
- **GitHub Pages**:仓库根目录已是 Pages 站点,访问 `https://<用户名>.github.io/planner/`。

首次打开会载入一批示例数据(含历史完成记录,让热力图有样子),可在 ⚙ 设置中一键清空。

### 后端(可选)

```bash
cd planner/server
npm install     # 仅 express 一个依赖
npm start       # 默认 http://localhost:8787
```

后端会**同址静态托管前端**,启动后直接打开 `http://localhost:8787` 即为完整应用。
数据持久化在 `server/data/db.json`(已被 .gitignore 忽略)。

连接方法:前端 ⚙ 设置 → 填入 API 地址(如 `http://localhost:8787`)→ 勾选「启用同步」→
「测试连接」确认连通 → 保存。此后每次改动自动防抖推送;断网时静默回退本地,恢复后自动合并。

#### API 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/tasks` | 全部任务(含墓碑,供合并) |
| POST | `/api/tasks` | 新建任务 |
| PATCH | `/api/tasks/:id` | 局部更新 |
| DELETE | `/api/tasks/:id` | 删除(墓碑化,30 天后清理) |
| POST | `/api/sync` | 整表上传,按 `updatedAt` 合并后返回权威结果 |
| GET | `/api/stats` | 完成率 / 连击 / 每日完成数等统计 |

## 设计小记

- **四象限用色经过校验**:Q1 玫红 / Q2 薰衣草紫 / Q3 沉金 / Q4 青蓝,浅深两套色板都
  通过了色觉缺陷(CVD)可分性与对比度的脚本化检查;卡片同时带 `Q1–Q4` 文字徽章,
  不单靠颜色传达身份。
- **热力图为薰衣草单色渐变**(浅→深五级),深色模式是独立取的色阶,不是简单反色。
- **重复任务按「出现」记账**:每天一条虚拟出现,勾选记入 `doneDates[日期]`,
  连击与热力图因此能逐日统计;拖拽不会破坏重复规则(会礼貌地提示去编辑)。
- **删除即墓碑**:同步时删除也能正确传播到另一端,30 天后自动清理。
- **撤销栈快照式**(60 步),添加/编辑/移动/勾选/删除全部可撤销,重做亦然。
