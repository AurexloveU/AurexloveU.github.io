# 奕苑 · 棋类游戏合集

为 Aurex 而作的三合一棋案:**国际象棋 / 五子棋 / 飞行棋**。
低饱和薰衣草紫 + 中文衬线的统一视觉;纯前端零依赖、离线可玩;可选启动 Node 后端开启联机对战。

## 运行方法

**纯本地(无需任何安装):** 直接用浏览器打开 `games/index.html`,或部署在任意静态托管
(如 GitHub Pages,本仓库即 `https://AurexloveU.github.io/games/`)。三款游戏全部可玩。

**联机对战(可选):**

```bash
cd games/server
npm install
npm start          # 默认 8787 端口,可用 PORT=xxxx 覆盖
```

- 后端会顺带静态托管整个 `games/`,访问 `http://localhost:8787/` 即是合集首页;
- 在国际象棋 / 五子棋页面切到「联机」,创建房间得到 4 位房号,另一人凭房号加入;
- 附带接口:`GET /api/leaderboard`(ELO 排行)、`GET /api/games`(近 50 局)、`GET /api/games/:id`(单局完整着法,可用于复盘)。

## 功能一览

### 国际象棋 `chess/`
- **规则完整**:王车易位、吃过路兵、兵升变(四选一)、将军/将死、逼和、五十步、三次重复、子力不足和棋。引擎通过 perft 标准局面测试(起始局面深度 1–4、Kiwipete 深度 1–3、过路兵局面深度 4 全部吻合)。
- **AI**:negamax + α-β 剪枝 + 吃子静态搜索,四档难度(低档带随机噪声,更像人)。
- **对局方式**:人机(可选执黑执白)/ 同屏双人 / 联机。
- **辅助**:走子提示、最后一步与将军高亮、被吃子力与子力差、悔棋(人机撤两步)、SAN 棋谱、**PGN 导出**、**复盘**(点棋谱任意一步回看,←/→ 键步进)、翻转棋盘。

### 五子棋 `gomoku/`
- 15×15 SVG 棋盘,悬停虚影、最后一手标记、坐标(A–O 跳过 I)。
- **AI 三档**:五元窗口启发打分 + 一步致胜/必挡检测;最高档对候选做一层攻防对抗。
- **可选禁手**(黑方):三三、四四、长连;恰五连仍判胜。轮到黑方时棋盘以红叉实时标出禁点。
- 人机(可选先后手)/ 双人 / 联机;悔棋(人机撤两步);手数记录。

### 飞行棋 `ludo/`
- 标准 52 格环道 + 各家 5 格跑道 + 终点;掷 6 起飞并奖励再掷(连掷三个 6 此轮作废);踩子送回基地;起飞格与 ★ 格为安全格;进终点须刚好走满。
- 2–4 人自由混搭:每个座位可设 玩家 / 电脑 / 关闭;电脑按 到达>踩子>起飞>避险>推进 的启发式行棋。
- 骰子摇动动画、棋子逐格滑行、同格棋子自动错位堆叠、行棋记录、终局排名(未完者按进度补排)。

### 后端 `server/`
- 房间制(4 位防混淆房号)双人对战,走子**服务器端校验**:国际象棋直接复用前端引擎逐着验证并自判终局;五子棋校验落点与轮次并判五连。
- 对局持久化到 `server/data/games.json`(含完整着法,可回放);玩家 ELO(K=32,初始 1200)存 `server/data/players.json`,终局随结果广播增减。
- 断线判负、认输、房满/房号错误等异常都有对应提示。

### 巧思
- 右上角三件套(全站记忆):**棋盘配色** ×5、**深浅主题**、**音效开关**;
- 音效全部由 WebAudio 现场合成(落子、吃子、将军、骰子、胜负、非法着法各不相同),零音频文件;
- 全部棋子为 Unicode 字形或内联 SVG,无一张图片、无一个外链 CDN。

## 已知简化(备注)
- 五子棋禁手为标准近似:不做连珠规则里"禁点递归"(假想补子点本身是禁手时的连锁判定);联机模式暂按自由规则(无禁手)。
- 飞行棋为常见家庭规则:安全格上不踩子、可与他人同格共存;无"迭子封路"。
- 联机以昵称记 ELO,无账号体系(演示用途)。
